# 📊 Análise de Cancelamento de Cartões de Crédito
Este projeto tem como objetivo analisar o comportamento de clientes de cartões de crédito, identificando padrões que levam ao cancelamento dos serviços. Utilizando Python e bibliotecas de análise de dados.

# 🔗 Fonte de dados 
https://www.kaggle.com/datasets/sakshigoyal7/credit-card-customers

# 🛠️ Tecnologias Utilizadas
- **Python**
- **Pandas**
- **Plotly.express**
- **Jupyter Notebook**

# 🔍 Principais Descobertas
- O cartão da categoria Blue apresenta a maior taxa de cancelamento entre os produtos analisados.
- Clientes com múltiplos produtos contratados demonstram menor propensão ao cancelamento.
- Clientes com maior volume de transações e limite de crédito elevado tendem a manter o cartão ativo.
- O aumento no número de contatos com a central de atendimento está associado a uma maior probabilidade de cancelamento.
